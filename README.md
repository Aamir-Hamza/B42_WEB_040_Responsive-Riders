# Educational Gamification App 🎮 📚

A gamified learning platform that revolutionizes education through interactive quizzes, rewards, and AI-powered personalization.

## 🌟 Live Demo

Check out the live application: [Educational Quiz App](https://educationquizzapp.netlify.app/)

Watch our project presentation: [YouTube Demo](https://youtu.be/IXrRxiSL1VA?si=j7gY6H271-HWg3Ln)

## ✨ Features

### 🎯 Interactive Quizzes and Challenges
- Real-time quiz transitions with dynamic feedback
- Timed challenges for enhanced engagement
- Animated scoreboards and personalized performance messages

### 🏆 Badges & Reward System
- Custom-designed badges and trophies
- Real-time achievement notifications
- Visual progress tracking
- Interactive level-up animations

### 📊 Leaderboards and Progress Tracking
- Real-time competitive rankings
- Animated rank transitions
- Customizable leaderboard filters
- Interactive progress dashboard with data visualization

### 🤖 AI-Powered Features
- Personalized quiz recommendations
- Performance-based learning paths
- Dynamic content adaptation

### 🎲 Additional Features
- Vocabulary building games
- Secure authentication system
- Comprehensive admin panel
- Mobile-responsive design

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone [repository-url]
```

2. Install dependencies:
```bash
npm install
```

3. Set up environment variables:
Create a `.env` file with necessary configurations

4. Start the development server:
```bash
npm run dev
```
